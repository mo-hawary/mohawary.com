# mohawary.com

GitHub Pages redirect for [mohawary.com](https://mohawary.com/), the canonical website and public developer profile for Mohamed ElHawary.

## Links

- Website: https://mohawary.com/
- GitHub: https://github.com/mo-hawary
- LinkedIn: https://www.linkedin.com/in/mohawary

## Redirect

- `index.html` redirects visitors to `https://mohawary.com/`.
- `404.html` redirects unmatched GitHub Pages paths to `https://mohawary.com/`.
- The redirect pages declare `https://mohawary.com/` as canonical and use `noindex,follow` so search engines keep the main site as the source of truth.
